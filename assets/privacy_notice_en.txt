Sealed Notebook privacy notice

Sealed Notebook (project Diary008) stores notes and reminder settings in the app's private storage. The app does not use a backend or analytics service and does not automatically upload note content or diagnostic logs. Android system backup rules are not explicitly disabled, so Android may back up or migrate private note and reminder files according to the device and account backup policy; this is system backup behavior, not an upload initiated by the app. Diagnostic logs are written to a directory excluded from Android system backup.

In-app notebook files are stored as plain text in the app's private storage. Optional password encryption applies only to backups exported by the user; it does not encrypt in-app files. The Android system file picker can be used to export plain-text or encrypted notebook backups and diagnostic logs. If a cloud drive or another third-party file provider is selected, manually exported files are handled by that provider and its privacy rules also apply.

Diagnostic logs are for local troubleshooting. They record time, event or status, device model, Android SDK, and app version; storage events may also include numeric volume numbers. Exception details usually contain an exception type and stack trace. Missing notification icon events may include an error code and resource message. Logs do not record note bodies, volume names, or backup passwords, and are never uploaded automatically. Logs can be exported or cleared in Data & diagnostics.

Uninstalling the app or clearing app data removes notes, reminder settings, and logs from private storage. Destroy all records removes notes but does not clear diagnostic logs or daily reminder settings. Files exported outside the app are not removed with the app; Android backups or device migration copies may also remain independently. Destroying notes does not guarantee forensic-level flash erasure and cannot retract copies outside the app. Keep needed data before deleting, uninstalling, or resetting a device, and protect exported files and encrypted backup passwords.
